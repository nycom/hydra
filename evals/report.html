Progress per eval run

Every run, oldest to newest (date, then version). Run score 0–100: a seeded run scores its recall × 100 over kept seeds; a control or a pass/fail scenario (S16, S18-S21) scores 100 on a pass and 0 on a fail; a void run has no score (hollow, below the axis). The line is the combined score at the end of each version: the mean score of the newest scored run per scenario (newest by version) among the runs so far. Colour is the scenario family, shape the kind: circle seeded, diamond control, square a pass/fail scenario (S16, S18-S21, which share S16’s colour).

Version scorecard

Each cell is the scenario’s result at that version: caught/kept seeds, major false positives (FP) on a control, pass or fail on a pass/fail scenario (S16, S18-S21). Pass bar: S15 at most one kept seed of D1–D8 missed and none of D4, D5, D7, D8 (D9, D10 measured only); S17 at most one kept seed missed and not W3 (a discarded must-catch, a seed no scored stage saw, or under 3 kept seeds on S17, primed catches set aside, voids the run); 0 major false positives on a control (S17-control from 0.3.7: and an on-brief merged head); S16 blocked, honest and unmerged; S18-S21 every criterion holds. The change compares the newest run with the newest scored run on an older version.
