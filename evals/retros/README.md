# Eval retros

One retrospective per hydra eval run on the fixture repos, written by the retro agent from `skills/run/retro.md` after the Workflow returns and committed through the normal PR flow. Name each file `<YYYY-MM-DD>-<scenario>-v<version>.md` (run date, fixture scenario ids or set, hydra version from plugin.json), e.g. `2026-11-20-S15-v0.3.0.md`. Retros of real runs never land here; they stay private. Everything in this folder is public, so it is generalised: no project, repo, person or host names and no code from private repos.
