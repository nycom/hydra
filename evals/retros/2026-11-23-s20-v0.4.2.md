## Changes, ranked
1. Test guard: judge the extent of an authorised edit, not only the file. An answer that authorises "edit the test to assert X" should not cover a rename; the author's "authorised test edit" line could carry the kind (values, rename, delete) so the guard can compare it with the answer. (Seen on 0.4.0 and 0.4.2.)
2. Gate wrapper: ship it as a script, as `run-cmd.mjs` is shipped, instead of a recipe each agent composes. The author broke the printed exit again. (Carried.)
3. A failed docs validation on a docs-only repo should reach the user: a question or an escalation naming the side branch and the finding, not only `otherDocs[].docs`. (New.)
4. Journal or cost.mjs: mark the call boundary in a resumed run's journal, or let cost.mjs report per call. Every multi-call scenario still needs a hand split. (Carried.)
5. Docs sync could settle carried docs-kind minors that its own commit resolves. (Carried.)
