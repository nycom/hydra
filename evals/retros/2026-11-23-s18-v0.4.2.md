- **No pass while unmerged.** Alpha's whole-branch pass did not run while `alpha-discount` was unmerged. Beta's did and passed, since beta's only planned workstream had merged (per-repo gating, as designed).
- **Resume probes are unique per call (0.4.1 change, confirmed).** Both state probes' prompts open with "call 2 (inputs <digest>)". The cache matched 0 of 11 saved results, so every agent ran live.

## Changes, ranked
1. Drop or settle a validator or fixer question once a later stage acts on it. When the whole-branch pass fixes a handed finding, any open question about the same finding (same file and test) should be dropped with a note, the way author soft-block questions already are. Otherwise the user is asked about done work, and the default contradicts what shipped.
2. Resume a dead review at review, not implement (repeat of the 0.4.0 retro). The probe sees the head unchanged since the last implement, so it could hand it straight to the review and save one author agent.
3. cost.mjs or the journal should mark call boundaries in a resumed run (repeat).
